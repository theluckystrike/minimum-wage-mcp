# Data sources

All pages were fetched on 2026-10-30. Rates in `src/data.ts` were copied from these pages; none is estimated.

## Baseline for every state

- US DOL, State Minimum Wage Laws (updated July 1, 2026): https://www.dol.gov/agencies/whd/minimum-wage/state
- US DOL, Minimum Wages for Tipped Employees (revised July 1, 2026): https://www.dol.gov/agencies/whd/state/minimum-wage/tipped

Each scheduled 2026 and 2027 change was then checked against the state labor department page or the statute below.
Where a state site blocked automated reads, the row says so and names what was used instead.

## Not confirmed on an official state page

- Arizona 2027 ($15.65): azica.gov blocks automated reads. Figure from search-index text of the ICA 2027 notice and a KTAR report.
- Connecticut 2027 ($17.48): portal.ct.gov unreachable. Figure from a WSHU report quoting the Labor Commissioner.
- Rhode Island 2027 ($17.00): dlt.ri.gov and the legislature site blocked or unreachable. Figure from search-index text of dlt.ri.gov and R.I.G.L. 28-12-3, plus a secondary report.
- Nebraska 2027: LB258 sets a 1.75 percent increase, but the Department of Labor figure could not be read, so the server returns no number.
- Nevada: $12.00 confirmed by US DOL; the 2024-07-01 start date comes from search results because labor.nv.gov was unreachable.
- Several federal-floor states (ID, IA, KS, KY, NH, ND, OK, PA, TX, UT, GA) use the US DOL tables because the state pages were blocked or returned 404.
